# iCodeForBananas

Personal dashboard built with Next.js 16, React 19, TypeScript, Supabase, and Vercel.

## Features

- **Task Board** — Kanban board (backlog / in-progress / done)
- **Space Math** — Cai's math practice progress dashboard
- **Songwriter** — Write, arrange and play jazz lead sheets

## Page Context Copier

[![Page Context Copier](https://raw.githubusercontent.com/iCodeForBananas/page-context-copier/main/store/promo-marquee.png)](https://github.com/iCodeForBananas/page-context-copier)

A Chrome extension that copies the page you're looking at as a clean, structured outline to paste into an AI agent. It keeps headings, lists, tables, forms, links and accessibility info, and leaves out the raw HTML. Everything runs locally. → [Source on GitHub](https://github.com/iCodeForBananas/page-context-copier)

## Tech Stack

- **Framework**: Next.js 16.1.1, React 19, TypeScript 5.9, App Router
- **Backend**: Supabase (`@supabase/supabase-js`, `@supabase/ssr`)
- **AI**: Google Gemini (`@google/genai`)
- **Deployment**: Vercel

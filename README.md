# iCodeForBananas

Personal exploration app built with Next.js 16, React 19, TypeScript, Supabase, and Vercel.

## Page Context Copier

[![Page Context Copier](https://raw.githubusercontent.com/iCodeForBananas/page-context-copier/main/store/promo-marquee.png)](https://github.com/iCodeForBananas/page-context-copier)

A Chrome extension that copies the page you're looking at as a clean, structured outline to paste into an AI agent. It keeps headings, lists, tables, forms, links and accessibility info, and leaves out the raw HTML. Everything runs locally. → [Source on GitHub](https://github.com/iCodeForBananas/page-context-copier)

## Space Math

[![Space Math](https://raw.githubusercontent.com/iCodeForBananas/space-math/main/docs/marquee/marquee.png)](https://github.com/iCodeForBananas/space-math)

A space-themed math game for kids in kindergarten through grade 3, on iPad, iPhone, Android and the web. Spaced repetition picks what to practice next, and there are no ads, no accounts and no tracking. → [Play in the browser](https://icodeforbananas.github.io/space-math/) · [Source on GitHub](https://github.com/iCodeForBananas/space-math)

## Guitar Tuner

[![Guitar Tuner](https://raw.githubusercontent.com/iCodeForBananas/guitar-tuner/main/docs/marquee/marquee.png?v=2)](https://github.com/iCodeForBananas/guitar-tuner)

A guitar tuner for iPhone, iPad, Android and the web. Pick a string, pluck it, and turn the peg until the line goes green. It measures against the string you picked rather than the nearest note, so even a badly slack string shows which way to turn. No ads, no accounts, and audio never leaves the device. → [Use it in the browser](https://icodeforbananas.github.io/guitar-tuner/) · [Source on GitHub](https://github.com/iCodeForBananas/guitar-tuner)

## 5×5 Tracker

[![5×5 Tracker](https://raw.githubusercontent.com/iCodeForBananas/five-by-five-tracker/main/docs/marquee/marquee.png)](https://github.com/iCodeForBananas/five-by-five-tracker)

A tracker for the classic 5×5 strength program on iPhone, iPad, Android and the web. Tap a lift after each set, and a 2:00 rest timer sits at the top. Each lift has a bar of reps in the last seven days against its weekly target, and the one furthest behind is flagged to do next, so you rotate lifts without being tied to Workout A or B. Data stays on the device. → [Use it in the browser](https://icodeforbananas.github.io/five-by-five-tracker/) · [Source on GitHub](https://github.com/iCodeForBananas/five-by-five-tracker)

## SimpleWinClean

[![SimpleWinClean](https://raw.githubusercontent.com/iCodeForBananas/simplewinclean/main/docs/marquee/marquee.png)](https://github.com/iCodeForBananas/simplewinclean)

Frees disk space on Windows without breaking anything. It scans 35 categories, from Windows Update and temp folders to browser and developer caches, and shows every item with its size before anything is deleted. Only the plainly safe categories are ticked by default, and personal folders are never touched. Standard library Python, no telemetry, no network code. → [Source on GitHub](https://github.com/iCodeForBananas/simplewinclean)

## SimpleWinUninstall

[![SimpleWinUninstall](https://raw.githubusercontent.com/iCodeForBananas/simplewinuninstall/main/docs/marquee/marquee.png)](https://github.com/iCodeForBananas/simplewinuninstall)

Uninstalls a Windows app with its own uninstaller, then finds what it left behind: folders, shortcuts, registry keys, services and scheduled tasks. Anything uncertain is listed but left unticked, and files go to the Recycle Bin so a removal can be undone. Standard library Python, no telemetry, no network code. → [Source on GitHub](https://github.com/iCodeForBananas/simplewinuninstall)

## Tech Stack

- **Framework**: Next.js 16.1.1, React 19, TypeScript 5.9, App Router
- **Backend**: Supabase (`@supabase/supabase-js`, `@supabase/ssr`)
- **AI**: Google Gemini (`@google/genai`)
- **Deployment**: Vercel

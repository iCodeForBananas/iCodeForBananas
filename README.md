# iCodeForBananas

Personal exploration app built with Next.js 16, React 19, TypeScript, Supabase, and Vercel.

## Page Context Copier

[![Page Context Copier](https://raw.githubusercontent.com/iCodeForBananas/page-context-copier/main/store/promo-marquee.png)](https://github.com/iCodeForBananas/page-context-copier)

A Chrome extension that copies the page you're looking at as a clean, structured outline to paste into an AI agent. It keeps headings, lists, tables, forms, links and accessibility info, and leaves out the raw HTML. Everything runs locally. → [Source on GitHub](https://github.com/iCodeForBananas/page-context-copier)

## Space Math

[![Space Math](https://raw.githubusercontent.com/iCodeForBananas/space-math/main/docs/marquee/marquee.png)](https://github.com/iCodeForBananas/space-math)

A space-themed math game for kids in kindergarten through grade 3, on iPad, iPhone, Android and the web. Spaced repetition picks what to practice next, and there are no ads, no accounts and no tracking. → [Play in the browser](https://icodeforbananas.github.io/space-math/) · [Source on GitHub](https://github.com/iCodeForBananas/space-math)

## Guitar Tuner

[![Guitar Tuner](https://raw.githubusercontent.com/iCodeForBananas/guitar-tuner/main/docs/marquee/marquee.png)](https://github.com/iCodeForBananas/guitar-tuner)

A guitar tuner for iPhone, iPad, Android and the web. Pick a string, pluck it, and turn the peg until the line goes green. It measures against the string you picked rather than the nearest note, so even a badly slack string shows which way to turn. No ads, no accounts, and audio never leaves the device. → [Use it in the browser](https://icodeforbananas.github.io/guitar-tuner/) · [Source on GitHub](https://github.com/iCodeForBananas/guitar-tuner)

## Tech Stack

- **Framework**: Next.js 16.1.1, React 19, TypeScript 5.9, App Router
- **Backend**: Supabase (`@supabase/supabase-js`, `@supabase/ssr`)
- **AI**: Google Gemini (`@google/genai`)
- **Deployment**: Vercel
